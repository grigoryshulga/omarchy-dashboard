# Agent guide

Этот репозиторий — исходная копия плагина `gshulga.dashboard`. Завершай каждую
задачу по следующему порядку.

## Завершение задачи

1. Перед началом проверь состояние рабочей копии:
   `git status --short --branch`.
2. После внесения изменений запусти полный набор проверок:
   `bash tests/all.sh`.
3. Переходи к установке только если проверки завершились успешно. Обнови
   локальную копию плагина на этой машине, скопировав содержимое репозитория в
   `~/.config/omarchy/plugins/gshulga.dashboard`:

   ```bash
   mkdir -p ~/.config/omarchy/plugins/gshulga.dashboard
   rsync -a --delete --exclude '.git/' ./ ~/.config/omarchy/plugins/gshulga.dashboard/
   ```

   Если `rsync` недоступен, используй эквивалентное копирование содержимого
   репозитория; не копируй каталог `.git`.
4. Проверь именно установленную копию:
   `omarchy plugin validate ~/.config/omarchy/plugins/gshulga.dashboard`.
5. Обязательно сразу после обновления локальной копии перезагрузи запущенный
   Omarchy Shell:
   `omarchy restart shell`.
6. Убедись, что в diff попали только изменения текущей задачи:
   `git diff --check` и `git diff`.
7. Подготовь коммит с коротким описанием результата:
   `git add <изменённые-файлы>` и `git commit -m "<описание изменения>"`.
   Не выполняй `git push`, если пользователь отдельно этого не попросил.

Задача считается завершённой только после успешных тестов, валидации
обновлённой локальной копии, перезапуска shell и создания коммита. Если любой
шаг не выполнен, явно сообщи об этом и не называй задачу завершённой.
