# Трекпад и трёхпальцевое переключение Spaces

Дата исследования: 2026-08-31. Проверены исходники Dashboard, действующая
локальная конфигурация Omarchy/Hyprland и первичная документация Hyprland.
Системные конфигурации не изменялись.

## Вывод

Поддержка тачпада в самом Dashboard пока неполная: обычные указательные
действия реализованы через `MouseArea`, но обработчиков `SwipeHandler`,
`MultiPointTouchArea` или иных QML-жестов в проекте нет. Поэтому
трёхпальцевый свайп не перелистывает **Spaces Dashboard**.

Для переключения **рабочих пространств Hyprland** такая поддержка штатно
есть. В Hyprland 0.56 используется Lua-конфигурация; официальный вариант
трёхпальцевого горизонтального жеста:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

Действие `workspace` переключает рабочие пространства, а `horizontal`
охватывает оба горизонтальных направления. Это жест композитора, а не
Dashboard, поэтому он не может сам по себе вызвать `dashboard.moveSpace()`.

Источник: [официальная документация Hyprland: Gestures](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/).

## Состояние этой машины

- Установлен Hyprland `0.56.2`.
- В `~/.config/hypr/input.lua` уже есть ровно эта строка и комментарий про
  переключение рабочих пространств, но строка закомментирована. Следовательно,
  жест сейчас не включён.
- `hyprctl getoption gestures:workspace_swipe_distance` возвращает значение
  по умолчанию `300` и `set: false`; прежние опции
  `gestures:workspace_swipe` и `gestures:workspace_swipe_fingers` в этой
  версии отсутствуют. Это согласуется с переходом на новую систему
  `hl.gesture`.
- В текущей сессии `hyprctl devices` не показывает тачпад (только внешние
  мыши), поэтому проверить жест на железе здесь нельзя.

## Важные настройки и границы

После регистрации жеста на поведение переключения влияют настройки раздела
`gestures`: расстояние свайпа (`workspace_swipe_distance`, по умолчанию
300 px), порог отмены (`workspace_swipe_cancel_ratio`, 0.5), направление
(`workspace_swipe_invert`, по умолчанию `true` для тачпада), блокировка
направления и создание нового рабочего пространства на правом краю
(`workspace_swipe_create_new`, по умолчанию `true`). Сенсорный экран
обрабатывается отдельной опцией и не заменяет тачпад.

Источник: [официальный справочник опций Hyprland: Gestures](https://wiki.hypr.land/Configuring/Basics/Variables/#gestures).

`input.touchpad.drag_3fg` — отдельная функция трёхпальцевого перетаскивания;
её не стоит включать одновременно без ручной проверки эргономики. Обычные
параметры тачпада (например, natural scroll и clickfinger) также находятся в
официальном [справочнике input/touchpad](https://wiki.hypr.land/Configuring/Basics/Variables/#touchpad).

## Рекомендация

Если цель — переключать системные рабочие пространства, достаточно раскомментировать
уже подготовленную строку в `~/.config/hypr/input.lua` и применить конфигурацию
Hyprland. Это внешняя пользовательская настройка и не требует изменения этого
плагина.

Если цель — листать именно Spaces внутри Dashboard, нужен отдельный этап
разработки: распознавать горизонтальный многопальцевый жест в QML и безопасно
вызывать `dashboard.moveSpace(-1|1)`. Его следует проектировать так, чтобы не
перехватывать прокрутку и жесты вложенных plugin pages; на данный момент этого
пути в коде нет.
