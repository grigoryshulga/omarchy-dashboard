# Dashboard 1.8.2

Released on September 11, 2026.

## Fixes

- Restore the installed plugin catalog on Omarchy 4.0.3, whose scoped registry
  no longer exposes every installed manifest directly to third-party hosts.
- Pass the environment required by Omarchy's public catalog and plugin-list
  helpers when Dashboard runs them with bounded, isolated processes.

## Updating

Existing Git installations can update with:

```bash
omarchy plugin update gshulga.dashboard
```

Existing layouts and plugin settings do not need to be reset. This patch does
not change the saved layout format.

See the [changelog](../../CHANGELOG.md) and
[changes since 1.8.1](https://github.com/grigoryshulga/omarchy-dashboard/compare/v1.8.1...v1.8.2).
