# Dashboard 1.8.1

Draft release notes. This candidate is being tested on `dev`.

## Fixes

- **Save only when needed:** Dashboard stops rewriting an unchanged layout after
  a successful save. Edits made while a save is running still persist, and a
  failed write can still be retried.
- Remove obsolete text-editor state and unused persistence configuration while
  keeping the existing text creation and inline editing controls.

## Updating

After 1.8.1 is published, existing Git installations can update with:

```bash
omarchy plugin update gshulga.dashboard
```

Existing layouts and plugin settings do not need to be reset. This patch does
not change the saved layout format.

See the [changelog](../../CHANGELOG.md) and
[changes since 1.8.0](https://github.com/grigoryshulga/omarchy-dashboard/compare/v1.8.0...dev).
