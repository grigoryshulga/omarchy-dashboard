# Dashboard 1.8.7

Released on October 16, 2026.

## Fixes

- Load system panels again — Weather, Clock, Network, Audio, Bluetooth, Power,
  Monitor, Tailscale, Dropbox, Elsewhen and Agents — on Omarchy builds that
  build a panel body on first open (Omarchy 4.0.0.r7013 and later). Dashboard
  embeds those panels by rewriting the shell's `KeyboardPanel` into its own
  in-process host, and that host did not implement the panel's new lazy
  `content` contract. The tiles failed to instantiate with `Cannot assign to
  non-existent property "content"` and stayed empty. The host now builds and
  exposes the content exactly as the shell does, including
  `loadedContent`, `loadedContentHeight` and `ensureContent()`.
- Accept `BarIconButton.labelText`, which the current shell adds for status
  pills such as the battery percentage. Without it a panel that sets the label
  could not be embedded at all.
- Report a panel that Dashboard cannot embed instead of showing an empty tile.
  The adapter now verifies the members a rewritten block sets against the host
  it will be rewritten to and names the missing one, so a future shell change
  surfaces as an error with a cause rather than a silent blank tile.

## Updating

Existing Git installations can update with:

```bash
omarchy plugin update gshulga.dashboard
omarchy restart shell
```

Existing layouts and plugin settings do not need to be reset. This patch does
not change the saved layout format. Cached embeddings are rebuilt
automatically, because the cache key includes the host files this release
changed.
