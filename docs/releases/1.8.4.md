# Dashboard 1.8.4

Released on October 14, 2026.

## Fixes

- Render Dashboard again on Omarchy installs updated to Qt 6.12 (quickshell
  0.3.2). Qt 6.12 ships its own `Color` type in QtQuick that shadowed the shell
  palette singleton, so tiles, dialogs and controls came up without colors.
  Every palette reference is now qualified as `Commons.Color`, the same
  migration the Shell itself applied.
- Lay out the grid canvas reliably on first open. Qt 6.12 evaluates dependent
  bindings eagerly, which turned the canvas-bounds feedback into a detected
  binding loop and broke the initial sizing of the canvas. Canvas bounds are
  now committed once per layout pass instead of re-entering the size binding.
- Disable the `ShellIpc` handlers that current Omarchy panels declare, so
  embedded copies of updated panels such as Bluetooth adapt correctly and no
  longer try to own the IPC target the bar panel already serves.

## Updating

Existing Git installations can update with:

```bash
omarchy plugin update gshulga.dashboard
```

Existing layouts and plugin settings do not need to be reset. This patch does
not change the saved layout format.
