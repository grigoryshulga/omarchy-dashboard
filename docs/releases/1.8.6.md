# Dashboard 1.8.6

Released on October 16, 2026.

## Fixes

- Keep Dashboard working when an Omarchy update changes the system values it
  reads. Every color, border, spacing value, and font now comes from one place
  with built-in fallbacks, so a system token that was renamed or removed leaves
  a readable surface instead of a broken binding. Before this patch a missing
  nested token such as `Color.popups.border` or `Style.font.subtitle` raised
  `Unable to assign [undefined]` and the affected dialogs, popouts, and tiles
  lost their colors.
- Read the focused monitor, the environment, and the screen list through that
  same place, and load the Hyprland and `hyprctl` pieces behind their own
  loaders. When one of them is unavailable Dashboard degrades — no focused
  monitor, no background blur — instead of failing as a whole.
- Popup, dialog, and card outlines follow the shell's control border width
  instead of a fixed 1 pixel, so themes that remove or thicken borders apply to
  Dashboard as well.

## Updating

Existing Git installations can update with:

```bash
omarchy plugin update gshulga.dashboard
```

Existing layouts and plugin settings do not need to be reset. This patch does
not change the saved layout format.
