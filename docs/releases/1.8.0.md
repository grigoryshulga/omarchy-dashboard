# Dashboard 1.8.0

Released on September 5, 2026.

## Highlights

- **Faster Space switching:** plugins preload in the background, and the page you
  open gets priority. Their state stays available while Dashboard is open.
- **Less friction with plugins:** hover to select, click to interact, and resize
  popouts without losing sight of Dashboard.
- **Cleaner editing:** icon actions, menus for small tiles, transparent tile
  backgrounds and Enter/Delete placement shortcuts.
- **Better text and dividers:** edit labels inline, choose text alignment, and
  adjust line thickness from the top bar.
- **Broader compatibility:** improved adaptation of existing Omarchy plugin
  panels, service handling, preferred sizes and assets.

## Updating

Existing Git installations can update with:

```bash
omarchy plugin update gshulga.dashboard
```

Existing layouts use left-aligned text, 2-pixel dividers and visible tile
backgrounds unless changed. Layouts and plugin settings do not need to be reset.

## Limits

- A slow plugin can still show loading if opened before its preload finishes.
- Hiding a tile background does not remove a background drawn inside the plugin.
- Native fallback windows retain the plugin's own window behavior.
