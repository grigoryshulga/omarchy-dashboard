# Dashboard 1.8.3

Released on September 20, 2026.

## Fixes

- Choose the Framed or Glass surface again. Dashboard now saves its own bar
  settings through the scoped Shell API, so the appearance buttons apply instead
  of being silently ignored.
- Keep the surface shown in the panel and the value saved in `shell.json` in
  sync, so switching to Glass (or back to Framed) always takes effect.
- Preserve the other appearance choices when one option changes, so switching
  the surface mode no longer drops the saved background preferences.

## Improvements

- Open Dashboard faster by reusing validated plugin adaptations when the
  installed plugins have not changed.

## Updating

Existing Git installations can update with:

```bash
omarchy plugin update gshulga.dashboard
```

Existing layouts and plugin settings do not need to be reset. This patch does
not change the saved layout format.

See the [changelog](../../CHANGELOG.md) and
[changes since 1.8.2](https://github.com/grigoryshulga/omarchy-dashboard/compare/v1.8.2...v1.8.3).
