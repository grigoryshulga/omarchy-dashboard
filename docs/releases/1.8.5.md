# Dashboard 1.8.5

Released on October 14, 2026.

## Fixes

- Load embedded plugins again on Omarchy builds whose `omarchy-shell` answers
  over its own socket (Omarchy 4.0.4 and later, including the Qt 6.12 update).
  The plugin-list helper ran with a hard-coded `OMARCHY_PATH=/usr/share/omarchy`,
  so against a shell running from any other path — a dev checkout or a custom
  install — the helper could not reach the live shell, the plugin catalog came
  back empty, and no tile content loaded. Helper processes now inherit the live
  session values (`OMARCHY_PATH`, `WAYLAND_DISPLAY`, `XDG_RUNTIME_DIR`) and only
  missing values fall back to the packaged defaults.

## Updating

Existing Git installations can update with:

```bash
omarchy plugin update gshulga.dashboard
```

Existing layouts and plugin settings do not need to be reset. This patch does
not change the saved layout format.

Note: the Omarchy update resets `shell.json`, which also drops the `plugins[]`
list that recorded third-party enablement. If a hosted third-party plugin still
does not render after this patch, re-enable it once with
`omarchy plugin enable <id>`.
